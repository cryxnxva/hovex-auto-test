# honex-auto-test

Мини-парсер объявлений Avito по артикулам товаров HONEX.

Парсер выполняет поиск по заданным артикулам, отбирает объявления
в состоянии «Новое» в Москве и Московской области, сортирует по цене
и сохраняет 5 самых дешёвых по каждому артикулу в `result.xlsx`.

> Документация дополняется. Полное описание: запуск, конфигурация,
> архитектура и логика работы — в процессе оформления.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Структура

```
main.py       # точка входа
parser.py     # логика парсинга HTML
config.py     # настройки (артикулы, регион, заголовки)
test_data/    # локальные HTML-файлы для graceful degradation
result.xlsx   # результат (не хранится в git)
```
